PMIX Menu List Report Builder
=============================

What you need: a Windows computer with Microsoft Excel installed. The report is built and
checked in Excel.

Keep everything in this one folder. Do not move or rename the files inside it.

What is in the folder
  PMIX Report Builder.exe          the app (double-click to start)
  Menu Items List.xlsx             the menu list the item names are checked against
  Menu Category reference.xlsx     the category outline
  decisions\                       the saved decisions (names, sections, approvals)
  Result\                          the reports and the mapping, after a run
  versions\                        the earlier Result files; created by the first run

How to run
  1. Save the new Raw data file in this folder (or choose it later with Browse).
     It needs two sheets, TOAST and SQUARE, in the same columns as before, with
     Gross Sales, Discount, Net Sales and Tax (blank) right after Qty. The SQUARE sheet may
     have only the header row.
  2. Double-click PMIX Report Builder.exe. The first start takes about half a minute.
  3. The start and end dates are filled in from the file. Change them if you want a shorter period.
  4. Press "Build report" and keep the window open. A full quarter takes about 15-20 minutes.
     The window shows which of the 4 steps it is on. Close any Excel file from the Result folder
     before you press the button.
  5. When it says the report is ready, press "Yes" to open the Result folder.
       USA PMix - Menu List Report.xlsx    the report
       USA PMix - Menu Mapping.xlsx        the category mapping behind it

New items
  If the file has items that have no category yet, the app builds a report marked DRAFT and tells
  you how many items are new. To finish the report:
    1. Open Result\USA PMix - Menu Mapping.xlsx and go to the Menu Category sheet.
    2. Filter the Review Status column for Pending.
    3. For each item, choose a Category from the list in the Category column, then change Review
       Status to Approved. You do not need to fill in Menu, Menu group or Item.
    4. If you cannot place an item, change Review Status to Excluded and write the reason in
       Review Notes. An item cannot be Approved without a Category.
    5. Save, close Excel, and press "Build report" again.
  The report is final when no item is Pending. If something in the file is not valid (for example
  an Approved item with no Category), the app lists every such item in one message so you can fix
  them all before running again.

Item names and the Menu Items List
  A leading # in a POS item name (for example #Americano) is removed in the report.

  Items that are not on the Menu Items List get a suggested list name in the mapping file
  (Result\USA PMix - Menu Mapping.xlsx, sheet Menu Category), in these columns at the end:
    Suggested Name       the name on the Menu Items List
    Suggested Section    the section it belongs to
    Match Confidence     High = the same words (plural, word order, & and capitals ignored);
                         Medium = a very similar spelling, which may be a typo or a different item
    Accept Suggestion    your decision: Yes = use the suggested name, No = keep the original name
  - New items with a High match are renamed automatically ("Auto" in Accept Suggestion). They are
    listed on the Changes sheet. Set Accept Suggestion to No to keep the original name.
  - Everything else is only a suggestion. Filter Suggested Name for non-blanks, check each line, and
    choose Yes where it is right. The name is used the next time you press "Build report".
  - Items you already approved are never renamed unless you choose Yes.
  - Names whose numbers differ (for example "2 Pieces" and "(1 piece)") are never suggested.

Amount columns
  Gross Sales, Discount, Net Sales and Tax are copied into the PMIXData sheet, right after Qty, and
  the PMIX PivotTable adds them as "Gross Sales ($)", "Discount ($)", "Net Sales ($)" and "Tax ($)"
  next to Qty for each period. While the raw data has them blank they show as "-". Fill them with
  numbers in the raw data (blank is fine, text is not) and they are added up in the PivotTable.

If something goes wrong
  Your files are not changed. Press "Show details", then "Copy details", and send the text to
  Herman.

Every run first moves the files that were in Result to versions\<date>-before-run-<date>\, so
nothing is overwritten.
