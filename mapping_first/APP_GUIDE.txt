PMIX Menu List Report Builder
=============================

What you need: a Windows computer with Microsoft Excel installed. The report is built and
checked in Excel.

Keep everything in this one folder. Do not move or rename the files inside it.

What is in the folder
  PMIX Report Builder.exe          the app (double-click to start)
  Menu Items List.xlsx             the menu list the item names are checked against
  Menu Category reference.xlsx     the category outline
  decisions\                       the saved decisions (names, sections, approvals)
  Result\                          the reports and the mapping, after a run
  versions\                        the earlier Result files; created by the first run

How to run
  1. Save the new Raw data file in this folder (or choose it later with Browse).
     It needs two sheets, TOAST and SQUARE, in the same columns as before, with
     Gross Sales, Discount, Net Sales and Tax (blank) right after Qty. The SQUARE sheet may
     have only the header row.
  2. Double-click PMIX Report Builder.exe. The first start takes about half a minute.
  3. The start and end dates are filled in from the file. Change them if you want a shorter period.
  4. Press "Build report" and keep the window open. A full quarter takes about 15-20 minutes.
     The window shows which of the 4 steps it is on. Close any Excel file from the Result folder
     before you press the button.
  5. When it says the report is ready, press "Yes" to open the Result folder.
       USA PMix - Menu List Report.xlsx    the report
       USA PMix - Menu Mapping.xlsx        the category mapping behind it

New items
  If the file has items that have no category yet, the app builds a report marked DRAFT and tells
  you how many items are new. Open Result\USA PMix - Menu Mapping.xlsx, sheet Menu Category, and
  filter Review Status for Pending. Fill in the category and set Review Status to Approved for
  each item you agree with, save, close the file, and press "Build report" again. The report is
  final when no item is Pending.

If something goes wrong
  Your files are not changed. Press "Show details", then "Copy details", and send the text to
  Herman.

Every run first moves the files that were in Result to versions\<date>-before-run-<date>\, so
nothing is overwritten.
